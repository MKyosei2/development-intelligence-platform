# 用語集

| 用語 | このWikiでの意味 |
|---|---|
| DIP | Development Intelligence Platform |
| Claim | 人や管理システムが主張する完了・進捗・状態 |
| Evidence | 検査、CI、実行、収集器等から得られた根拠情報 |
| Revision / SHA | 対象となるコードの具体的な改訂版 |
| Project Truth | ClaimとEvidenceの整合性・鮮度・信頼度を評価する考え方／機能領域 |
| QA | Quality Assurance。品質を確認し問題の発見・予防につなげる活動 |
| Collector | ゲームや外部ツールから情報を収集して報告する接続処理 |
| Quality Gate | 定義された品質要件に基づく判定 |
| Regression | 変更後に以前できていたことが壊れる退行 |
| Golden Master | 比較基準として保存する検証用の結果・画像 |
| Soak Test | 長時間稼働させ、累積的な問題を調べる負荷試験 |
| SLI / SLO | サービス品質の指標／その目標 |
| RTO / RPO | 復旧に許容される時間／データ損失の目標 |
| RFC | 採用前の設計提案・意見募集文書 |
| ADR | 採用された設計判断と理由の記録 |
| PR / Issue | 変更レビュー／作業や問題の追跡単位 |
| Runtime Verified | 実際の対象実行環境で検証した状態 |
| NOT_EVALUATED | 必要な条件が整わず評価していない状態 |
| Provenance | 成果物やEvidenceがどのように生成されたかの来歴 |
| SBOM | ソフトウェア構成部品の一覧 |
| False Positive | 実際には問題がないのに不具合と検出した結果 |
