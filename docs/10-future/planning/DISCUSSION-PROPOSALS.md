# GitHub Discussions で検討したい設計テーマ

**Status: Proposed.** リポジトリのDiscussionsを有効化した後に投稿する。ファイルの追加だけで議論スレッドは作成されない。

## D-01: UnityとUnrealのQAの共通Evidenceモデル

**問い:** Adapter固有情報を維持しながら、どの字段を共通QA結果に統一するか。

**議論の材料:** 実Engineのログ、同じQA項目の差異、別SHAの防止、情報喪失の可能性。

**決定後:** 必要に応じてRFC-001を更新し、実装Issueを起票。

## D-02: GPU・Visual QAの判定基準

**問い:** Pixel diff、SSIM、実GPUキャプチャ、レビューをどう組み合わせるか。

**議論の材料:** 異なるGPUやAPI、HDR、非決定的エフェクト、誤検知のケース。

**決定後:** RFC-003とQA-002へ反映。

## D-03: AIに許可するコード修正範囲

**問い:** どんな操作を許すか。セキュリティ・企業機密をどう保護するか。

**議論の材料:** Workspace隔離、API送信ポリシー、生成テストの改変検知、人手の承認。

**決定後:** RFC-002とARCH-003に反映。

## D-04: サービス提供形態

**問い:** 個人利用、企業専用環境、共通マルチテナントをどの順番で検証するか。

**議論の材料:** コスト、データ隔離、配布先OS、契約と運用負担。

**決定後:** ARCH-002とPRD-002を更新。
