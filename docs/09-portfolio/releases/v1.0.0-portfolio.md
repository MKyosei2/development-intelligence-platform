# Development Intelligence Platform v1.0.0-portfolio

Feature countを増やすことではなく、**verifiabilityとreviewer clarity**を重視したPortfolio milestone。

## 主な内容

- Demo、screenshot、architectureを備えた簡潔なreviewer-first README。
- Exact-commit Evidence policyと保存されたhistorical benchmark/QA/runtime Evidence。
- Fail-closedな公開前secret scanとcurrent-SHA CI gate。
- Browser-firstのDevelopment Intelligence / Defect Intelligence / Management Operations surface。
- Management Operationsをcode-behindと再利用可能なcockpit/tab componentへ分割。
- Portfolio package内のempty `.razor` pageを0件化。
- 今後の開発向けConventional Commit validation。

## 検証Policy

このreleaseは、release tagのbuild/tests/publication-safety checkが成功した場合のみ公開する。`docs/09-portfolio/evidence/verified-baseline/`のhistorical measurementは記録済みcommitへboundしたままとし、このreleaseのmeasurementとしてre-labelしない。

Unity-equipped runnerが対応するexact-revision Evidenceを生成しない限り、Unity full-runtime verificationを主張しない。
