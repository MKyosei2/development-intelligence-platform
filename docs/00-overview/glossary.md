# Glossary

| 用語 | 定義 |
|---|---|
| Collector | 外部ツールの情報を共通Reportへ変換するAdapter |
| PipelineRun | CI、Build、Test、Collectorの1回の実行 |
| Metric | FPS、Memory、Build Sizeなどの数値 |
| QualityIssue | 品質上の問題 |
| Baseline | 比較対象となる過去の正常値 |
| QualityGate | Pass、Warning、Failの判定 |
| Evidence | 判定根拠となるMetric、Issue、Commit |
