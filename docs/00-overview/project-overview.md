# Development Intelligence Platform

DIPは、GitHub、CI/CD、ゲームエンジン、DCCツール、テスト、性能計測、タスク情報を統合し、PM・プロデューサー・テックリードの意思決定を支援する開発運営基盤です。

## 解決する問題
- 情報が複数ツールへ分散している
- 品質劣化の発見が遅い
- Pull Requestの危険度が分からない
- リリース判断が経験へ依存する
- 日次報告作成に時間がかかる

## MVP
Project、PipelineRun、Metric、QualityIssue、Quality Gate、Dashboard、Python分析、Collector Report 1.0を対象にします。
